# cmb gold quote

招商银行黄金行情插件，作者：kesh。

支持 VS Code 和 IntelliJ IDEA，默认每 5 秒刷新一次报价。
接口地址、请求参数和刷新间隔可以在插件设置中修改。

## 下载安装

请在本项目的 Releases 页面下载对应安装包：

- VS Code：下载 `.vsix` 文件，从扩展面板选择“从 VSIX 安装”。
- IntelliJ IDEA：下载 `.zip` 文件，在插件设置中选择“从磁盘安装插件”。
  IDEA 版本针对 2025.3 平台编译，其他版本兼容性尚未验证。

安装后，VS Code 可通过命令面板搜索 `cmb gold quote` 打开行情；
IDEA 可通过右侧 `cmb gold quote` 工具窗口打开行情。

## 说明

行情数据通过招商银行接口获取，网络不可用或接口变化可能导致查询失败。
报价仅供参考，实际交易以招商银行页面和成交结果为准。
