# cmb gold quote

招商银行黄金行情插件，作者：kesh。

支持 VS Code 和 IntelliJ IDEA，默认每 5 秒自动刷新一次报价。
可在插件设置中修改自动刷新间隔，最小为 5 秒。

## 功能

- 显示实时买入价、卖出价、今日涨跌幅和报价时间。
- 根据美元兑人民币参考汇率，折算买入价的美元/盎司数值。
- 显示参考汇率，以及金衡盎司与克的换算关系。
- 自动刷新和手动刷新独立运行；两次手动刷新至少间隔 1 秒。
- 显示插件运行时间及手动刷新提示。

## 下载安装

请在本项目的 Releases 页面下载对应安装包：

- VS Code：下载 `.vsix` 文件，从扩展面板选择“从 VSIX 安装”。
- IntelliJ IDEA：下载 `.zip` 文件，在插件设置中选择“从磁盘安装插件”。
  IDEA 版本针对 2025.3 平台编译，其他版本兼容性尚未验证。

安装后：

- VS Code：通过命令面板搜索 `cmb gold quote` 打开行情。
- IDEA：通过右侧 `cmb gold quote` 工具窗口打开行情。

## 说明

- 黄金行情通过招商银行接口获取，网络不可用或接口变化可能导致查询失败。
- 美元/盎司数值根据买入价和每日参考汇率折算，并非国际黄金实时报价。
- 报价仅供参考，实际交易以招商银行页面和成交结果为准。
